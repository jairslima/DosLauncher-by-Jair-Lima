# DosLauncher-by-Jair-Lima

## Descrição
Scripts para rodar programas DOS e Windows 16 bits no Windows 64 bits, por menu de contexto ou DOSBox-X.

## Stack
PowerShell; usa otvdm e DOSBox-X (não incluídos).

## Estrutura
Ver a lista de arquivos na raiz e o README.md.

## Comando essencial
`powershell -ExecutionPolicy Bypass -File install-menu.ps1`

## Estado atual
Versão pública inicial (2026-10-17), extraída do projeto original do autor.

## Problemas conhecidos
Testado apenas no Windows.
